# Login

A login screen. A Yandex Practicum study project.

## What it does

The screen has a username, a password, a Remember me switch, and a Log in button. The button turns on when the username has at least three characters. With the switch on, the username is stored on the device and filled in on the next launch. The password is neither checked nor saved.

## Stack

UIKit, UserDefaults.

## Run

```bash
git clone https://github.com/dpogonia/Login-YANDEX.git
cd Login-YANDEX
open ProfilePage.xcodeproj
```

Run the **ProfilePage** scheme on an iPhone simulator.
