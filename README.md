# Login

Экран входа. Учебный проект Яндекс Практикума.

## Что умеет приложение

На экране имя, пароль, переключатель Remember me и кнопка Log in. Кнопка включается, когда в имени не меньше трёх символов. Если переключатель включён, имя сохраняется на устройстве и подставляется при следующем запуске. Пароль не проверяется и не сохраняется.

## Стек

UIKit, UserDefaults.

## Запуск

```bash
git clone https://github.com/dpogonia/Login-YANDEX.git
cd Login-YANDEX
open ProfilePage.xcodeproj
```

Запустите схему **ProfilePage** на симуляторе iPhone.
